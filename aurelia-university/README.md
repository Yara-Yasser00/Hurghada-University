# Aurelia University

Fictional British university marketing website built with Angular 19 (standalone components).

Inspired by the **information architecture and UX patterns** of major UK university sites — without copying logos, trademarks, proprietary assets, or copyrighted text.

## Run

```bash
cd aurelia-university
npm install
npm start
```

Open http://localhost:4200

## Routes

- `/` Home
- `/study` `/research` `/admissions` `/about`
- `/colleges` `/news` `/events` `/contact`

## Notes

- Images are royalty-free Unsplash placeholders.
- Search uses local mock data via `UniversityDataService`.
